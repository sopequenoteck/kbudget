# Quickstart: Angular Text Scale

**Branch**: `093-angular-text-scale`

## Lancer

```bash
cd app && npx ng serve
```

## Vérification rapide

1. Ouvrir `http://localhost:4200/settings/appearance`
2. Section "Taille du texte" visible sous le sélecteur de thème ?
3. Sélectionner "Petit" → textes réduits partout ?
4. Sélectionner "Grand" → textes agrandis partout ?
5. Aperçu sous le sélecteur change en temps réel ?
6. Recharger la page → le réglage est conservé ?
7. Les icônes gardent leur taille fixe (pas affectées) ?

## Tests

```bash
cd app && npx vitest run
```
